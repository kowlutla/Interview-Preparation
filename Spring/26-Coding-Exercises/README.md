# Spring Coding Exercises

This collection contains 85 numbered exercises. Each entry provides a problem statement, requirements/expected behavior, a reference approach, common mistakes, and validation steps. Some advanced items intentionally describe solution outlines and should be converted into fully runnable sample projects during the final code-validation pass.

- [1–25: Core Spring and REST](01-Core-and-REST-Exercises.md)
- [26–50: Operations and advanced](02-Operations-and-Advanced-Exercises.md)
- [51–70: Testing and integration](03-Testing-and-Integration-Exercises.md)
- [71–85: Security, messaging, and Cloud](04-Security-Messaging-Cloud-Exercises.md)

Recommended approach: attempt each task before reading the reference approach, write tests for both success and failure paths, and confirm API availability against the target Spring version.
