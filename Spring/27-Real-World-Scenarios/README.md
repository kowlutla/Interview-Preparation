# Spring Real-World Scenarios

This collection contains 75 production-oriented scenarios. Each scenario frames symptoms, investigation, resolution, trade-offs/prevention, and an interviewer follow-up. Use them to practice evidence-based incident reasoning rather than memorizing fixes.

- [1–10: Container, web, and transactions](01-Container-Web-Transactions.md)
- [11–20: Resilience, security, and operations](02-Resilience-Security-Operations.md)
- [21–30: Architecture and design](03-Architecture-and-Design.md)
- [31–45: Additional production scenarios](04-Additional-Production-Scenarios.md)
- [46–55: Additional production scenarios continued](05-Additional-Production-Scenarios.md)
- [56–65](06-Scenarios-56-to-65.md)
- [66–75](07-Scenarios-66-to-75.md)

For each scenario, structure the answer around impact, evidence, root cause, mitigation, durable fix, and validation. Include a rollback plan for production changes.
