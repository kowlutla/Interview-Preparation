# Spring Mock Interviews

Five interview tracks are provided. Practice answering aloud, then use follow-ups to test whether you can reason about mechanisms and trade-offs rather than recite annotations.

1. [Junior Java Developer — Spring fundamentals](01-Junior-Spring-Fundamentals.md)
2. [Mid-Level Backend Engineer — Boot and REST](02-Mid-Level-Backend.md)
3. [Senior Backend Engineer — transactions, security, performance](03-Senior-Backend.md)
4. [Microservices Engineer — resilience and messaging](04-Microservices-Engineer.md)
5. [Senior Product-Based Company — architecture and production reasoning](05-Senior-Product-Company.md)

Suggested scoring rubric per answer: correctness, mechanism, practical example, failure mode, trade-offs, version awareness, and clarity. Do not claim a topic is hands-on experience unless you have actually built or operated it.
