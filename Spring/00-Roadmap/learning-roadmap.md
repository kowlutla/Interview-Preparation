# Spring Learning Roadmap

## Learning sequence

1. **Object management:** IoC, DI, bean definitions, scopes, lifecycle, and configuration.
2. **Framework interception:** proxies, AOP, transactions, caching, async execution, and method security.
3. **Boot mechanics:** starters, auto-configuration, environment/property binding, application events, and startup diagnostics.
4. **Web APIs:** Spring MVC, request mapping, validation, DTOs, exception mapping, serialization, and API contracts.
5. **Data:** transaction boundaries, JDBC abstractions, repository abstractions, and Spring Data JPA integration.
6. **Security:** filter chains, authentication, authorization, OAuth 2.0 resource servers, JWT validation, CSRF, and CORS.
7. **Quality:** unit tests, slice tests, integration tests, MockMvc, Testcontainers, and test-context behavior.
8. **Operations:** clients, resilience, observability, health checks, graceful shutdown, deployment, and performance investigation.
9. **Specialized models:** WebFlux, messaging, scheduling, caching, Spring Cloud, and custom auto-configuration.
10. **Interview synthesis:** solve exercises, analyze incidents, then complete mock interviews.

## Study loop

For each chapter, explain the main abstraction without notes, build a minimal runnable example, identify the proxy/container/runtime behavior, add a positive and failure-path test, read the official reference for the exact version, and practice a trade-off question.

## Completion criteria

A chapter is ready for interview use only when its concepts, version notes, examples, and failure modes have been reviewed. File existence alone is not completion. The handbook should be counted against targets only after duplicate-question and exercise audits.
